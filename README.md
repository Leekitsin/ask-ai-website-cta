# Ask AI Website CTA

A simple marketing experiment exploring how websites can use
pre-filled AI prompts as a new type of CTA.

## The idea

Traditional B2B website journey:

Visitor → Website → Product/Service Page → Contact Us

AI-assisted journey:

Visitor → Website → Ask AI → Conversation → Solution Discovery

Instead of forcing visitors to navigate through multiple product
and service pages, an "Ask AI" CTA can start a conversation with
an AI assistant.

## Example

This project was inspired by an implementation I came across
where a website allowed visitors to ask ChatGPT, Claude and
other AI assistants about the company using pre-filled prompts.

For the Sniper Technologies example, the AI is first given
context about the company and its broad technology capabilities.

Instead of immediately asking the visitor a long list of
qualification questions, it asks:

"What are you interested in?"

The visitor can then respond naturally.

For example:

- "I need Microsoft 365."
- "We need Adobe licenses."
- "We are looking for MacBooks for our employees."
- "We are setting up a GCC."
- "We need help managing our devices."

The AI can then continue the conversation based on the
visitor's interest.

## Why this is interesting for marketers

The goal isn't to build another chatbot.

The idea is to use existing AI platforms as an additional
discovery layer for a website.

This could potentially be adapted by:

- B2B technology companies
- SaaS companies
- Agencies
- Professional services firms
- IT service providers
- Consultancies
